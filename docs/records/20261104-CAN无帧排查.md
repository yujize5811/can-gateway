# CAN 无帧排查（代码侧排除）

- 日期：2026-11-04
- 对应指标：T1 位定时（未通过）
- 固件 commit：见 MDK-ARM/can_gw

## 1. 我预期发生什么

PCAN-View 每 20 ms 收到一帧 0x201，8 字节。

## 2. 实际发生了什么

PCAN-View Receive 窗口始终 Empty。Status: OK，Overruns: 0。

## 3. 差在哪

已逐层排除软件：

| 层 | 检查 | 结论 |
|---|---|---|
| 时钟 | HSE 8M ×9 = 72M，APB1 /2 = 36M | 正确 |
| 位定时 | Prescaler 8 / BS1 6 / BS2 2 / SJW 1 | 500 kbps，正确 |
| 引脚 | PA11 输入(CAN_RX)，PA12 复用推挽(CAN_TX) | 正确 |
| 时钟使能 | CAN1 + GPIOA | 正确 |
| 模式 | CAN_MODE_NORMAL | 正确 |
| 启动 | HAL_CAN_Start | 已调用 |
| 发送 | StdId 0x201 / DLC 8 / 20 ms | 已写入 while |
| 链接 | map 里 main 引用 HAL_CAN_AddTxMessage | 已链接进固件 |
| 烧录 | Programming Done + Verify OK | 已写入芯片 |

剩余未验证：CANH / CANL 物理连线。

## 4. 结论·下一步

CAN 发送方必须有接收方 ACK 才认为发帧成功；无 ACK 会一直重发并产生错误帧，接收端也不会显示。
因此"一帧都没有"等价于"两个节点没有连在同一条有效总线上"。

待测：
1. 断电蜂鸣：模块 CANH ↔ 分析仪 H、模块 CANL ↔ 分析仪 L
2. 上电电压：H 对 GND、L 对 GND 均应约 2.3 V
3. 对调 H/L 后重试
