# 容量验证

- 日期：2026-11-01
- 对应指标：硬件确认（不属于 T1–T9）
- 固件 commit：无

## 1. 我预期发生什么

三块新买的 F103CBT6，读 0x1FFFF7E0 应该都是 0x0080，即 128 KB。

## 2. 实际发生了什么

旧板 DShanMCU-F103：读到 0x0040，64 KB。
新板：SW Device 显示 No target connected，没读到。

## 3. 差在哪

- 现象：新板连不上，旧板正常进调试界面。
- 排查过程：Connect 改 Normal → 时钟降到 1 MHz → 用手压紧排针 → 换旧板，旧板能连。
- 根因：新板 SWD 那 4 个针没焊，杜邦线只靠机械接触，2 MHz 的信号过不去。
- 修复：待焊，电脑维修店，11 个针。
- 代价：从 21:30 到 23:00，一晚上。

## 4. 结论·下一步

新板焊完重读容量。旧板的 0x0040 属正常（C8T6），可直接用于 11 月 CAN 项目。
